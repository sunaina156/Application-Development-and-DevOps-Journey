# ***WEB APPLICATION***

## Standalone Application
- Need to install in your system
- Require OS services to work
- It doesn't require internet connection
- ex: MS Office, powerpoint
 
## Web Application
- A web application or web app is a client-server software application in which the client (or user interface)
  runs in a web browser
- A typical application has multiple components:

                  Web Application
                        │
          ┌─────────────┼─────────────┐
          ↓             ↓             ↓
      Frontend       Backend       Database
  
## Website vs Web Application

### Website
- A website mainly provides information or content to users.
- ex: portfolio, blog, news website, documentation
user -> website -> information

### Web Application
- A web application allows users to interact with the application and perform actions.
- ex: instagram, gmail, netflix, amazon, url shortener

user -> frontend -> backend -> database -> response -> user

# ***CLIENT && SERVER***

## Client
- The browser we use is called web client
- Client side application used for connecting to a seb server over HTTP
- Web client are software designed to help users to access rsources on the Internet
- ex: chrome, firefox, mobile application, react application, postman, curl
- Client is the software that sends a request to a server.

## Server
- The computer that stores the resources is called server
- Web server is a computer that stores web server software and websites files.
- The computer that stores these resources used by client is called web server

# ***FRONTEND && BACKEND && DATABASE***

## Frontend

- Frontend is part of an application the user sees and interacts with.
- Frontend Technologies includes HTML, CSS, JavaScript, React, Vue, Angular

## Backend
- It is part of the application that runs on the server and contains the application's logic
- It can validate data, process requests, apply business logic, generate short URLs, authenticate users, communicate with databases, return responses

## Database
- It stores application data
- Backend communicates with the database
- Backend   --------------------->  Database
                   SQL Query
